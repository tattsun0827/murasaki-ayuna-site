# 紫あゆな 公式ビジネスサイト

沖縄を拠点に活動する歌手・ラジオパーソナリティ「紫あゆな」のプロトタイプサイトです。

## ページ

- `index.html` — Home
- `about.html` — About
- `service.html` — Service
- `works.html` — Works
- `contact.html` — Contact
- `manual.html` — GAS設定マニュアル（サイトナビゲーションには非掲載）

## お問い合わせフォーム

1. `manual.html` の手順でGoogle Apps Scriptをデプロイします。
2. 発行されたURLを `assets/js/contact.js` の `GAS_WEB_APP_URL` に設定します。

現在はプレースホルダーのため、URL設定前の送信は行われません。

## GitHub Pages

リポジトリの Settings → Pages で、`main` ブランチのルートを公開元に設定します。
